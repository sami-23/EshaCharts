==================================================
EshaCharts Update Log
==================================================

--------------------------------------------------
v2.0 - 2026-04-29
--------------------------------------------------
Compare Mode - Equal Width segments:
- Added "Equal Width" checkbox in Display Options (Sequential layout only)
- When enabled, each file occupies the same horizontal space on the x-axis regardless of its data range or slider trim amount
- Implemented by normalizing each file's trimmed x data to [0, 1] before offsetting
- Separator lines and file label annotations also respect the equal-width spacing

--------------------------------------------------
v1.9 - 2026-04-29
--------------------------------------------------
Compare Mode - Data Range Improvements:
- Added per-file Invert toggle next to each data range slider
- Inverts only that file's y-data independently (stacks with global Invert Data toggle)
- Slider thumb color now matches the file's curve color for easy identification
- Adjusting slider or toggling invert resets zoom so graph autoranges to new data

--------------------------------------------------
v1.8 - 2026-04-29
--------------------------------------------------
Data Range Sliders (Compare Mode):
- Added dual-handle X-axis range sliders per file in compare mode
- Sliders appear in "Data Range" section of CompareControlPanel, one per file
- Each slider has a Start and End handle to trim raw data rows for that file
- Graph redraws immediately as handles are dragged
- Applies to both Sequential and Overlay layouts
- X values (start/end) are displayed below each slider

--------------------------------------------------
v1.7 - 2026-04-29
--------------------------------------------------
- File selector now pre-selects all files by default
- Reverted: Y Zoom carry-over feature (to be redesigned)
- Reverted: style choice dialog (Raw Data / Use Saved Styles)

--------------------------------------------------
v1.6 - 2026-04-29
--------------------------------------------------
- Compare mode default layout changed from Overlay to Sequential
- Reverted: compare mode independent zoom/pan feature (to be redesigned)
- Added: version number printed to browser console on load

--------------------------------------------------
v1.5 - 2026-04-29
--------------------------------------------------
Bug Fix:
- Fixed compare mode showing datasets cramped to opposite sides with empty space in between
- Root cause: files with non-overlapping absolute x-ranges (e.g. time-shifted measurements) caused the x-axis to span the full combined range
- Fix: "X Start from 0" (normalizeX) now defaults to ON when entering compare mode, shifting each file's x-data to start from 0 so curves overlay correctly
- User can still disable "X Start from 0" in Display Options if absolute x values are needed

--------------------------------------------------
v1.4 - 2026-04-27
--------------------------------------------------
UI:
- Added version number display (e.g. "v1.4") in the header next to the app title

--------------------------------------------------
v1.3 - 2026-04-27
--------------------------------------------------
Graph View State Persistence:
- Zoom and pan state is now saved per file - navigating away and back restores the exact view
- Compare mode view (zoom/pan) is also saved independently while compare is active
- Inline title edits (double-clicking chart title or axis labels in Plotly) are now saved back to settings and persist across navigation
- Added "Reset View" button in ControlPanel (alongside Undo/Redo) to restore autorange for the current file
- Added "Reset View" button at the top of CompareControlPanel for compare mode
- Plotly toolbar "Reset Axes" button also clears the saved zoom state in sync

--------------------------------------------------
v1.2 - 2026-04-07
--------------------------------------------------
Chart Types:
- Added per-curve chart type selector (Line, Bar, Scatter, Area, Step)
- Each curve can independently use a different chart type

Data Tools:
- Added per-curve math operations: Multiply (scale factor) and Offset
- Added per-curve Transform: Derivative (dy/dx) and Integral (cumulative)
- Added per-curve Smoothing slider (moving average, window 0-50)
- Added per-curve Peak Detection toggle (marks maxima in red, minima in blue)

UX Improvements:
- Added grid toggle (show/hide grid lines)
- Added log scale option for X and Y axes independently
- Added crosshair mode (unified X hover showing all Y values)
- Added undo/redo for all settings changes (50-step history)
- Added style presets: save, load, and delete graph styles (stored in browser)

Export:
- Added "Copy to Clipboard" button (copies graph as PNG image)
- Added "Export CSV (with transforms)" button (exports modified data)

--------------------------------------------------
v1.1 - 2026-04-07
--------------------------------------------------
- Added "Invert Data" checkbox in single file view
- Added "Invert Data" checkbox in compare view (overlay and sequential)
- Inversion negates all Y values (positive becomes negative, vice versa)
- Graph updates immediately when toggled
- Inversion applied in batch export as well
